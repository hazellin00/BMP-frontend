# BMP-frontend (前端 Vue PWA)

這是一個專為設計的血壓記錄簡單好操作的網頁應用，支援 PWA 技術，安裝後可像原生 App 一樣從手機桌面啟動。

## 🌟 核心功能
- **類 App 體驗**: 透過 PWA 實現無網址列介面與離線支援。
- **長輩友善 UI**: 大字體、高對比顏色、直覺的底部導覽列。
- **數據視覺化**: 整合 Chart.js 展示 7-2-2 紀錄趨勢。
- **AI 飲食建議**: 串接後端 Gemini AI 提供個人化健康指南。

## 🛠️ 技術棧
- **框架**: Vue 3 (Vite + Composition API)
- **樣式**: Tailwind CSS
- **資料庫**: Supabase Client (Auth & Storage)
- **上架平台**: Vercel (HTTPS 正式環境)
